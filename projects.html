Adaptive Network Management: Cell Tower Prioritization in Crisis

R&D capstone with 2degrees focused on prioritising cell towers during disruptions using geospatial analysis and ranking logic.

I worked on building and refining a data pipeline that merges telecom tower coverage with supporting datasets, then produces a ranked list of towers to help guide restoration decisions during outages.

  • Designed Python data pipelines and REST APIs to process and analyse large cell tower and geospatial datasets
  • Developed ranking and scoring algorithms to support data-driven emergency response decisions
  • Collaborated in a four-person Agile (SCRUM) team across development, testing, documentation, and stakeholder feedback
  • Delivered and documented an end-to-end solution for an industry client, ensuring usability and alignment with operational requirements

TuneTalk: Music-Driven Social Discovery Platform

Full-stack web application exploring how shared music taste can enable meaningful social connection using Spotify data.

TuneTalk explores how shared music taste can become a meaningful signal for social discovery. By combining Spotify listening data with a modern web stack, the project focuses on turning external APIs into human-centred features rather than raw data displays.

  • Developed a full-stack MERN web application integrated with the Spotify REST API for music discovery and user matching
  • Designed MongoDB data structures and implemented API-driven features for user profiles, preferences, and content discovery
  • Collaborated in a five-person Agile (SCRUM) team using GitHub and Trello, contributing to development, testing, and performance improvements
MongoDB Express React Node.js Spotify API
